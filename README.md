# StockNote · 재고노트 v7.4

Windows / macOS용 독립형 범용 재고관리 프로그램입니다.

- 품번 및 옵션(사이즈·색상·용량)별 재고 관리
- 엑셀 일괄 등록, 입출고 및 취소 이력
- 주문 수집 및 `발송중` 전환 시 재고 차감
- 사용자마다 로컬에 데이터를 저장하는 독립형 프로그램

## 다운로드

현재 자동 빌드는 GitHub **Actions**에서 먼저 확인할 수 있습니다. 이 단계에서 생성되는 파일은 테스트용 빌드 결과물이며, 정식 Releases 게시 전까지 개발 배포판으로 취급하세요.

**API 연동 상태:** 스마트스토어는 공식 커머스API 연결과 주문 조회를 구현했습니다. POIZON은 공식 주문 API의 App Key/Secret 서명과 주문 목록 조회를 구현했습니다. 두 채널 모두 실제 판매자 계정·API 권한을 통한 최종 검증은 필요합니다. KREAM은 승인된 자체 개발용 API 주소·인증방식·주문 필드 명세가 있어야 연결할 수 있으며 키만 넣어서 자동 연동된다고 보장하지 않습니다.

Windows 및 macOS 앱은 [Releases](https://github.com/duehddnr12-spec/stocknote/releases)에서 제공합니다. **릴리스에 ZIP 파일이 게시되기 전에는 앱 배포가 완료된 것이 아닙니다.**

## 빌드

Windows와 macOS 각각에서 Python 3.12 / PyInstaller로 생성하며, GitHub Actions 워크플로를 사용합니다.

## 보안

공개 저장소에는 스마트스토어 API 비밀키, 주문 개인정보, 실제 재고 백업을 올리지 마세요. 스마트스토어 실계정 주문 API와 macOS 앱의 실제 사용 검증은 별도로 필요합니다.

## 데이터 이전

이전 버전에서 **전체 백업**한 뒤 복원하고 상품·옵션별 수량을 확인하세요. 서로 다른 PC의 재고는 자동 동기화되지 않습니다.

## 앱 자동 업데이트 (v7.4부터)

프로그램 화면의 **업데이트 확인** 버튼으로 GitHub Releases의 더 새로운 미리보기 버전을 확인할 수 있습니다. 사용자가 명시적으로 **백업 후 업데이트 설치**를 승인해야 다운로드와 설치가 시작됩니다. 설치 전 상품, 주문, 옵션, 입출고 기록을 운영체제별 사용자 디렉터리에 백업하고, GitHub 릴리스에 게시된 SHA-256 검증값과 다운로드가 일치할 때만 설치합니다.

- Windows: 사용자 권한으로 실행되는 PowerShell 교체 도우미가 기존 프로세스 종료 후 `StockNote.exe` 교체·재실행
- Mac: `ditto`로 앱 번들을 해제한 뒤 시스템 셸 도우미가 `StockNote.app` 교체·재실행
- 설치 전 이전 앱 파일을 `.previous-시간` 이름으로 보관하며, 파일 교체 실패 시 이전 파일 복구 시도
- 브라우저의 기존 `http://127.0.0.1:8765` IndexedDB 주소가 유지되어 기존 상품과 기록을 다시 읽음. **다른 브라우저/주소에서는 재고가 자동 동기화되지 않음**
- 앱 API 비밀키는 원래 메모리에만 저장되기 때문에 **앱을 재시작하면 API 키를 다시 입력해야 함**. 이것은 영구 저장하지 않으려는 의도된 보안 정책임
- v7.3 이전 앱에는 업데이트 기능이 없으므로, v7.4를 **처음 한 번은 수동으로 다운로드 및 설치**해야 함
- 앱 폴더에 쓰기 권한이 없거나 macOS 보안 정책에서 차단되면 자동 교체가 실패할 수 있음. 서명·공증된 정식 앱 배포 전까지는 시험용 배포판

업데이트 전 백업 파일 기본 위치: Windows `%LOCALAPPDATA%\StockNote\backups`, macOS `~/Library/Application Support/StockNote/backups`.

## 테스트

`python -m unittest discover -s tests -v`로 버전 비교·백업 저장·압축 경로 검사를 실행합니다. Windows/Mac 사용자 환경에서 실제 앱 교체 후 기록 보존 테스트는 추가 검증이 필요합니다.
