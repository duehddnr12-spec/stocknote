API 설정

자동 API 조회는 로컬 앱 서버에서 공식 계정 인증을 완료한 경우 이용할 수 있습니다. 브라우저 HTML 파일만 열었을 때는 파일 업로드를 사용하세요.

스마트스토어 · 공식 커머스API 연결애플리케이션 ID + 시크릿 등록으로 실제 주문 수집
연결 전
커머스API센터에서 앱 등록 ↗

ID와 시크릿은 실행 중인 이 PC의 로컬 서버 메모리에만 보관됩니다. HTML 파일·브라우저 저장소·백업에 넣지 않습니다. 주문 API 권한과 호출 IP 등록이 필요할 수 있습니다.

연결 테스트는 네이버 토큰 발급과 주문 조회 권한을 확인합니다. 주문 수집 버튼을 누르면 먼저 미리보기가 표시됩니다. 주문 반영하기를 누르면 재고 차감 없이 발송준비로 등록됩니다. 이후 발송중으로 변경을 누르면 해당 품번 재고가 한 번 차감됩니다. 이 작업은 판매채널의 실제 배송 상태를 변경하지 않습니다. 옵션 관리코드가 없으면 잘못된 재고 차감을 막기 위해 별도 품번 연결이 필요합니다.

스마트스토어 커머스API 앱 ID와 시크릿을 입력한 다음 연결 정보를 적용하세요. v6.3은 주문 조회 요청 속도 제한과 HTTP 429 자동 재시도를 지원해요.

KREAM 전문셀러 · API 연결 설정내 API 키를 입력하고 공식 주문 API에 연결합니다.
연결 전

입력한 키는 이 PC에서 실행한 연결 서버의 메모리에만 보관하고 HTML·브라우저 저장소·백업 파일에는 저장하지 않습니다.

API 키만으로는 주문 주소나 인증 방식이 확인되지 않습니다. KREAM 측에서 제공한 주문 조회 API 명세의 URL을 입력하세요.

고급 설정 · 공식 API 문서에 따라 지정

표시된 경로는 일반적인 형식의 예시이며 KREAM 공식 필드명이 아닙니다. 실제 명세에 맞게 변경해야 합니다. 한 번의 요청에서 응답된 목록만 수집하며 페이지네이션은 추가 연동이 필요합니다.

주의: ERPia처럼 특정 연동업체용으로 발급한 KREAM 키는 다른 프로그램에서 사용할 권한이 없을 수 있어요. 직접 개발용 API 주소·인증 규격·권한을 먼저 확인하세요. 공식 주소가 확인되기 전에는 실제 주문 조회를 할 수 없습니다.

연결 정보가 등록되지 않았습니다. 공식 API 주소가 없다면 기존 주문 엑셀·CSV 업로드를 이용하세요.

POIZON · 공식 주문 조회 APIApp Key + App Secret · 승인된 주문 API 권한이 필요합니다.
연결 전

공식 API: POST /dop/api/v1/pop/api/v1/order/generic_list. 권한 승인 후 실제 연결이 가능합니다. POIZON의 판매자 원본 품번/사이즈를 기준으로 매칭하고 모호한 옵션은 수동 연결 대상으로 남겨둡니다. API 키는 앱 실행 중인 로컬 서버 메모리에만 보관합니다. 공식 주문 목록 API 문서
